# 🧠 DSA Patterns - Problem Solving Repository

This folder contains problems organized by **problem-solving patterns**, which are essential for mastering Data Structures & Algorithms and performing well in coding interviews.

Instead of focusing only on topics (like arrays or strings), this approach emphasizes **how to solve problems efficiently using patterns**.

---

## 🚀 Goal

* Build strong **pattern recognition skills**
* Solve problems faster in interviews
* Understand the **why behind solutions**
* Improve coding efficiency and logic building

---

* 🔹 Two Pointers
* 🔹 Sliding Window
* 🔹 Prefix Sum / Prefix Product
* 🔹 Hashing (HashMap / Set)

## 🧠 How I Approach Problems

For each problem, I focus on:

* Identifying the **correct pattern**
* Writing a **clean and optimized solution**
* Understanding **time & space complexity**
* Learning from mistakes and improving

---

## ⚡ Why Patterns Matter

In coding interviews, problems are rarely about just "arrays" or "strings".

They are about recognizing patterns like:

* Sliding Window
* Two Pointers
* Prefix Sum

Mastering these patterns helps in solving **unseen problems quickly and confidently**.
